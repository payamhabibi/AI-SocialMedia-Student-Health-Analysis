# AI and Social Media Impact on Student Health and Grades 📊🤖

An end-to-end Machine Learning project analyzing the impact of daily Artificial Intelligence tool usage and Social Media consumption on students' mental and physical health.

---

## 🚀 Project Overview
This project explores a dataset of 16,000+ student records to uncover hidden behavioral patterns, correlations, and predictive insights regarding how screen time, social media, and AI tool dependency affect student well-being. We frame this as a **Classification problem** to predict whether a student is at risk regarding mental health.

---

## 🛠️ Tech Stack & Libraries
* **Python** (Pandas, NumPy)
* **Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-Learn (Logistic Regression, KNN, SVM, Naive Bayes, Random Forest, Gradient Boosting)

---

## 📈 Methodology & Steps
1. **Data Loading & Cleaning:** Handled duplicates, checked missing values, and prepared data types.
2. **Exploratory Data Analysis (EDA):** Visualized feature distributions and correlation heatmaps.
3. **Feature Engineering:** Created a binary target variable (`Mental_Health_Risk`) based on median scores to identify at-risk students.
4. **Machine Learning Modeling:** Trained and evaluated **6 different classification algorithms**:
   * Random Forest Classifier
   * Logistic Regression
   * Support Vector Machine (SVM)
   * Gradient Boosting Classifier
   * Naive Bayes
   * K-Nearest Neighbors (KNN)
5. **Evaluation & Visualization:** Compared models using Accuracy, Classification Reports, and Confusion Matrices.

---

## 🏆 Model Performance Summary
* **Random Forest:** ~67.38% (Best Performance)
* **Logistic Regression:** ~66.25%
* **Gradient Boosting / SVM:** ~65.94%
* **Naive Bayes:** ~65.81%
* **K-Nearest Neighbors:** ~61.12%
